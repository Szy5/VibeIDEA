# AlphaXiv Paper Lookup

在 alphaxiv.org 上查找任何 arxiv 论文，以获得结构化的 AI 生成的概述。这比尝试阅读原始 PDF 更快、更可靠。

## 何时使用

- 用户共享 arxiv URL（例如 `arxiv.org/abs/2401.12345`）
- 用户提及论文 ID（例如`2401.12345`)
- 用户要求您解释、总结或分析研究论文
-用户共享 alphaxiv URL（例如`alphaxiv.org/overview/2401.12345`）

## 工作流程

### 步骤1：提取论文ID

从用户提供的任何内容中解析论文ID：

|输入|论文 ID |
| ------------------------------------------------------ | -------------- |
| `https://arxiv.org/abs/2401.12345` | `2401.12345` |
| `https://arxiv.org/pdf/2401.12345` | `2401.12345` |
| `https://alphaxiv.org/overview/2401.12345` | `2401.12345` |
| `2401.12345v2` | `2401.12345v2` |
| `2401.12345` | `2401.12345` |

### 步骤 2：获取机器可读的报告

``bash
curl -s "https://alphaxiv.org/overview/{PAPER_ID}.md"
```

这将返回中间机器可读报告 - 针对 LLM 消耗优化的论文的结构化详细分析。一次调用，纯 Markdown，无 JSON 解析。

如果返回 404，则尚未生成本文的报告。

### 步骤 3：如果您需要更多详细信息，请获取完整的论文文本

如果报告不包含用户询问的具体信息（例如特定的方程、表格或部分），获取完整的论文文本：

``bash
curl -s "https://alphaxiv.org/abs/{PAPER_ID}.md"
```

这会以降价形式返回论文的完整提取文本。仅将此用作后备 — 报告通常就足够了。

如果返回 404，则全文尚未处理。作为最后的手段，请引导用户访问位于“https://arxiv.org/pdf/{PAPER_ID}”的 PDF。

## 错误处理

- **第 2 步**404：未生成本文的报告。
- **第 3 步**404：尚未为此提取全文paper.
