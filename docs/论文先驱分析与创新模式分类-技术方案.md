## 3. 阶段一：prior-work 抽取方案

### 3.1 输入模型

`summarize_recommended_papers.py` 以推荐 JSONL 为输入，每行映射为 `RecommendedPaper`：

- `title`
- `summary`
- `score`
- `abstract`
- `authors`
- `venue`
- `year`
- `source`
- `url`
- `doi`
- `arxiv_id`

### 3.2 PDF 获取策略

核心函数：

- `infer_arxiv_id()`
- `resolve_pdf_url()`
- `get_pdf_storage_path()`
- `ensure_pdf_downloaded()`

策略如下：

1. 若 URL 是 arXiv，则直接映射到 `https://arxiv.org/pdf/<id>.pdf`
2. 若 URL 来自 ACL Anthology，则使用 `<paper_url>.pdf`
3. 若 URL 来自 AAAI OJS，则按页面 HTML 做多级解析：
   - `citation_pdf_url`
   - `/article/download/...`
   - `/article/view/<submission>/<galley>` 转换为 download URL

PDF 本地落盘到：

- `raw_paper/pdfs/venue=<VENUE>/year=<YEAR>/...pdf`

### 3.3 文本抽取策略

核心函数：

- `extract_pdf_text()`

优先使用：

1. `PyMuPDF`
2. `pdftotext` fallback

默认限制：

- 最多前 15 页
- 最多约 8000 词

### 3.4 GPT prior-work extraction

核心函数：

- `analyze_prior_works()`
- `call_gpt5()`

这里保持了 Sci-Reasoning prior-work extraction 的主任务逻辑：

- 输出 `prior_works`
- 输出 `synthesis_narrative`

说明：

1. 该阶段本身不负责 `innovation_classification`
2. `innovation_classification` 是阶段二追加的结果

### 3.5 输出结构

核心数据结构：

- `PriorWork`
- `PriorWorkAnalysis`

每篇论文输出：

1. `prior_work_analysis_<paper_id>.json`
2. `prior_work_analysis_<paper_id>.md`

额外输出：

- `manifest.json`
- `*_download_manifest.json`

### 3.6 断点续跑

断点续跑逻辑在 `process_paper()` 中：

- 若对应 JSON 与 MD 已同时存在，则跳过
- 重新运行同一命令时，仅补跑未完成样本

强制重跑：

- 使用 `--overwrite`

### 3.7 建议运行方式

#### 只下载

```bash
python -u backend/summarize_recommended_papers.py \
  --input raw_paper/recommended_acl_aaai_top300_min7.65.jsonl \
  --pdf_dir raw_paper/pdfs \
  --output_dir results/recommended_acl_aaai_top300_min7.65_prior_work \
  --mode download \
  --download_workers 8
```

#### 只分析

```bash
python -u backend/summarize_recommended_papers.py \
  --input raw_paper/recommended_acl_aaai_top300_min7.65.jsonl \
  --pdf_dir raw_paper/pdfs \
  --output_dir results/recommended_acl_aaai_top300_min7.65_prior_work \
  --mode analyze \
  --gpt_workers 10 \
  --model_name gpt-5
```

## 4. 阶段二：thinking-pattern 分类方案

### 4.1 设计来源

该阶段逻辑来源于 Sci-Reasoning 中的：

- `thinking_patterns_llm_analysis/code/classify_all.py`

当前项目中的适配实现为：

- [backend/classify_thinking_patterns.py](/home/sunzongyuan/projects/VibeIDEA/VibeIDEA/backend/classify_thinking_patterns.py)

### 4.2 输入

输入来自 prior-work 抽取后的：

- `prior_work_analysis_*.json`

读取字段：

- `paper_title`
- `synthesis_narrative`

### 4.3 taxonomy 加载

默认 taxonomy 路径：

- `/home/sunzongyuan/projects/Sci-Reasoning/thinking_patterns_llm_analysis/results/pattern_taxonomy.json`

脚本会读取：

- `taxonomy[*].id`
- `taxonomy[*].name`
- `taxonomy[*].description`

### 4.4 批量分类策略

关键参数：

- `--batch_size`，默认 `5`
- `--model_name`，可设置为 `gpt-5`

做法：

1. 将一个 batch 中多篇论文的 `synthesis_narrative` 拼接到同一个 prompt
2. 让模型一次返回该 batch 所有论文的分类结果
3. 将结果解析为：
   - `primary_pattern`
   - `secondary_patterns`
   - `confidence`
   - `reasoning`

随后本地补充：

- `primary_pattern_name`
- `secondary_pattern_names`

### 4.5 回写逻辑

脚本会原地更新每个 JSON：

```json
"innovation_classification": {
  "primary_pattern": "P04",
  "secondary_patterns": ["P03"],
  "confidence": "high",
  "reasoning": "...",
  "primary_pattern_name": "Modular Pipeline Composition",
  "secondary_pattern_names": ["Representation Shift & Primitive Recasting"]
}
```

### 4.6 checkpoint 与 summary

输出文件：

- `thinking_pattern_classification_checkpoint.json`
- `thinking_pattern_classification_summary.json`

用途：

1. 中断后恢复进度
2. 保存 token / cost 汇总
3. 审计已分类样本

### 4.7 建议运行命令

```bash
python -u backend/classify_thinking_patterns.py \
  --input_dir results/recommended_acl_aaai_top300_min7.65_prior_work \
  --model_name gpt-5 \
  --batch_size 5 \
  --checkpoint_path results/thinking_pattern_classification_checkpoint.json \
  --summary_path results/thinking_pattern_classification_summary.json \
  2>&1 | tee results/thinking_pattern_classification.log
```

## 5. 元信息校准方案

### 5.1 目标

对 prior-work 抽取结果进行标准化，重点修正：

- `paper_title`
- `paper_arxiv_id`
- `prior_works[*].title`
- `prior_works[*].arxiv_id`

### 5.2 匹配来源

核心数据源：

1. arXiv API
2. OpenAlex
3. Crossref

### 5.3 匹配策略

#### 目标论文层

1. 先从推荐源 JSONL 里恢复原始元信息
2. 若已有 arXiv ID，直接用 arXiv canonical title
3. 若有 DOI，优先 DOI 直查 OpenAlex / Crossref
4. 否则使用标题搜索

#### prior works 层

1. 若已有 arXiv ID，直接校准标题
2. 否则依次搜索：
   - OpenAlex
   - arXiv title search
   - Crossref
3. 按标题相似度、年份、作者做重排
4. 只有超过阈值才自动写回

### 5.4 打分与阈值

打分函数：

- `score_candidate()`

权重：

- 标题相似度：`0.75`
- 年份匹配：`0.15`
- 第一作者匹配：`0.10`

默认阈值：

- `target_threshold = 0.78`
- `prior_threshold = 0.82`

### 5.5 日志

输出：

- `enrichment_log.jsonl`

日志内容包含：

- `before`
- `after`
- `applied`
- `match`
- `file`

同时控制台打印每条变更的标题与 arXiv ID 前后对比。

## 7. 已知问题与建议

### 7.1 GPT 接口稳定性

- 并发过高时可能卡住或出现失败请求
- 推荐先从小并发压测再放大

### 7.2 `innovation_classification` 不是阶段一自然产物

必须执行阶段二分类脚本，才能得到 `innovation_classification`

### 7.3 Markdown 暂不自动同步更新

阶段二和元信息校准主要回写 JSON，不会自动重渲染已有 Markdown。

如果后续需要对齐，建议追加一个：

- `regenerate_markdown_from_json.py`

### 7.4 taxonomy 仍依赖 Sci-Reasoning 目录

当前默认直接引用 Sci-Reasoning 中的 `pattern_taxonomy.json`。如果未来需要完全独立部署，建议把 taxonomy 拷贝进本仓库 `docs/` 或 `data/`。
