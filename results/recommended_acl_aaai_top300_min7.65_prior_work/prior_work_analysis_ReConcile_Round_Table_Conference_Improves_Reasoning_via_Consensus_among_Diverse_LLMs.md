## Synthesis: How Prior Work Led to This Paper

Multi-agent debate showed that having multiple agents argue can improve factuality and reasoning, but prior implementations typically used multiple instances of the same model, limiting diversity and the scope for genuine cross-model feedback. Building on this, the debate+judge paradigm introduced a separate adjudicator and also identified Degeneration-of-Thought, where iterative processes fail to create novel reasoning when models are overconfident, reflecting a core weakness of self-reflection methods like Self-Refine. Independently, self-consistency demonstrated that sampling multiple reasoning paths and aggregating them via majority vote boosts accuracy, crystallizing the value of ensembling diverse rationales. Complementing that, LLM-Blender established that ensembling different LLMs via ranking and fusion can unlock complementary strengths across model families, though without interaction or explanation exchange. Concurrently, teacher–student work showed that explanations from a teacher can correct and improve a student’s reasoning, indicating that well-crafted explanations can actively persuade a model to revise errors. The broader conceptual backdrop comes from the society-of-minds view: complex cognition emerges from interacting specialized agents. Taken together, these strands revealed a clear opportunity: leverage genuinely diverse models to exchange explanations, explicitly learn to persuade with corrective exemplars, and then aggregate with calibrated confidence rather than an unweighted vote or an external judge. ReConcile synthesizes these insights into a round-table, multi-model, multi-round dialogue that groups stances, conditions agents on ‘convincing’ examples to generate persuasive explanations, elicits per-round confidence, and produces a confidence-weighted consensus—turning static ensembling and single-model debate into collaborative consensus-building among diverse LLMs.
